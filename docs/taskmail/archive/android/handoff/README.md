# TaskMail 历史 Handoff

本目录承接以下材料：

- 已完成或暂停的会话续接说明
- live/manual smoke 的过程记录
- 只对当时那次执行有效的运行态 pitfall

这些文件保留的价值是：

- 追溯某次验证当时看到了什么
- 理解某个运行态坑为什么被发现
- 回放某条主线在收口前经历过哪些中间状态

这些文件不再承担：

- 当前实现 truth
- 当前验证摘要
- 当前 active planning

当前主线入口请回到：

- `docs/taskmail/README.md`
- `docs/taskmail/planning/README.md`
